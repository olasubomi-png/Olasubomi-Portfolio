# Images Folder

Add these image files to make the gallery and profile sections look great:

| File name            | Used for                         |
|----------------------|----------------------------------|
| profile.jpg          | Your profile photo in the hero   |
| bot-screenshot.jpg   | Gallery: WhatsApp bot screenshot |
| aws-server.jpg       | Gallery: AWS server screenshot   |
| setup.jpg            | Gallery: Your coding setup photo |

## Recommended sizes:
- profile.jpg: 400x400 px (square), JPG or PNG
- gallery images: 800x500 px (landscape), JPG

The site works perfectly without these images — placeholders are shown automatically.
